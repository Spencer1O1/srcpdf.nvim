# v1

Prove open-in-system-viewer. Compile can wait one step. Only `.tex` is a source.

## In

- Plugin name `srcpdf.nvim` (`require("srcpdf")`)
- `sources = { "tex" }`
- `:PdfOpen` from `foo.tex` opens sibling `foo.pdf` with `vim.ui.open`
- Neovim stays on the `.tex`
- If the PDF is missing, say so (do not compile yet)

## Out

- pdfreader, Kitty, Ghostty, ImageMagick, poppler
- In-buffer page rendering
- Compile-then-open
- Side-by-side
- Non-sibling output paths

## Done when

From `main.tex`, one keymap opens `main.pdf` in the desktop PDF viewer. The `.tex` buffer is still current.
