# v1

Prove the toggle. Compile can wait one step.

## In

- Depend on pdfreader.nvim
- Keymap: current window `foo.tex` ↔ sibling `foo.pdf`
- If the PDF is missing, say so (do not compile yet)
- After the user compiles some other way, toggling back should show the new page (`redrawPage` if needed)

## Out

- Our own viewer
- Compile-on-toggle
- Side-by-side
- Non-sibling output paths

## Done when

From `main.tex`, one keymap shows `main.pdf` in pdfreader. The same keymap returns to the `.tex`.
