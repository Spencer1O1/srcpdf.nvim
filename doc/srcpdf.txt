*srcpdf.txt*	Compile a source file to PDF and open the system viewer

==============================================================================
INTRO							*srcpdf* *srcpdf.nvim*

srcpdf.nvim compiles `.tex`, `.md`, or `.html` to `out/<stem>.pdf` and opens
that file with |vim.ui.open|. Neovim stays on the source buffer.

	.tex    latexmk / tectonic / pdflatex
	.md     pandoc, then weasyprint (documentation, not math)
	.html   weasyprint

Requires Neovim 0.10+.

The plugin does not set a keymap.

==============================================================================
USAGE							*srcpdf-usage*

							*:PdfOpen*
:PdfOpen		Write the current buffer if it is modified, compile
			into `outdir`, open the PDF. From a `.pdf` buffer,
			open that file without compiling.

							*srcpdf.open()*
require("srcpdf").open()
			Same as |:PdfOpen|.

							*srcpdf.pdf_path()*
require("srcpdf").pdf_path({path})
			Return `outdir/<stem>.pdf` for a configured source, or
			{path} if it is already a PDF. Return `nil` otherwise.

Missing tools produce one warning plus an install command. A leftover PDF is
not opened.

Add `out/` to the project's `.gitignore`.

==============================================================================
SETUP							*srcpdf-setup*

require("srcpdf").setup({opts})

`setup()` is optional. With lazy.nvim, pass the same table as `opts`.

	sources					(table, default below)
		Extensions that pair with `outdir/<stem>.pdf`.
		Default: `{ "tex", "md", "html", "htm" }`

	outdir					(string, default "out")
		Directory next to the source for the PDF and aux files.

Example: >
	require("srcpdf").setup({
	  sources = { "tex", "md", "html", "htm" },
	  outdir = "out",
	})
<
==============================================================================
HEALTH							*srcpdf-health*

							*:checkhealth-srcpdf*
:checkhealth srcpdf	Reports which LaTeX, pandoc, and HTML PDF tools are
			found. Missing tools include an install command.

==============================================================================
NOT						*srcpdf-not*

This plugin is not an in-terminal PDF renderer, a VimTeX replacement, or
SyncTeX.
